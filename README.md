# Cole Randell · Portfolio

A plain HTML site with no build step. Vercel serves the files as they are.

- `index.html`: the main page (intro, work, experience, skills, contact)
- `first-step.html`: the First Step case study
- `style.css`: shared styles (light and dark mode)
- `Cole_Randell_Resume.pdf`: the resume the site links to. Replace this file to update it.
- `img/`: photo and screenshots

## Updating

- **Photo:** save it as `img/cole.jpg`, then follow the comment above the `CR` circle in `index.html`.
- **Screenshots:** save them as `img/today.png`, `img/add-task.png` and `img/too-big.png`, then follow the comment in `first-step.html`.
- **Going live:** push to `main` and Vercel redeploys.
